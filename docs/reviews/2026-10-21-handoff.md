## Keadaan Git dan deployment

Source revamp dan tujuh rujukan handover sudah di-commit serta di-push ke branch `codex/auto-deploy-fe-be`. Mulai dari branch itu saat Claude melakukan sinkronisasi; `main` belum menerima revamp ini. Server preview lokal sudah dihentikan. Mekanisme VPS di `scripts/poll_deploy_vps.sh` hanya mengambil `main`, lalu membangun frontend dan menjalankan migrasi backend pada lingkungan produksi. Push branch kerja adalah handover source, bukan rilis online. Jangan merge ke `main` atau menjalankan skrip deploy tanpa keputusan rilis terpisah serta pemeriksaan data, migrasi, dan backup.
