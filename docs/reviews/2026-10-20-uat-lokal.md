Tes backend mencakup operasi jurnal dan otorisasi, posting gaji, tagihan, kegiatan, laporan, serta aturan COA. Tes regresi baru memastikan akun legacy `1103` bernama Perlengkapan tidak dipakai sebagai piutang kasbon dan aturan posting dialihkan ke `114`.

**Batas tahap awal:** Interaksi browser pada database demo utama bersifat baca dan buka form agar datanya tetap bersih. Pemeriksaan layar berupa sampel per role, bukan seluruh kombinasi filter dan ukuran viewport. Alur tulis browser dan PDF dilanjutkan di database UAT terpisah pada bagian berikut. Status ini khusus lokal dan bukan persetujuan deploy.

## Lanjutan: simpan/ubah browser pada database UAT terpisah

Frontend `127.0.0.1:4180` diarahkan ke API lokal `:8001`, yang memakai database baru `bee_uat_browser_20261020`. Database demo utama tidak diubah; pembacaan balik menunjukkan siswa dengan NIS `UAT-20261020-01` hanya ada di database UAT. Server UAT dihentikan setelah pemeriksaan; database UAT dipertahankan untuk meninjau ulang hasil.

Cetak laporan *Laba rugi* dibuat dari sesi Kepala Sekolah menjadi PDF UAT enam halaman A4 (tersimpan lokal, tidak disertakan di GitHub publik). Halaman pertama dan terakhir diperiksa visual: judul, periode, tabel, total beban Rp3.150.000 dan rugi periode tampil tanpa terpotong. Pembayaran TU dan realisasi Guru belum masuk laporan karena jurnalnya masih draf; pendapatan yang tercatat tetap Rp0. PDF memuat banyak akun bersaldo nol sehingga panjangnya enam halaman; ini kandidat pemadatan tampilan cetak, bukan kegagalan hitung. Satu respons 401 muncul di konsol selama pergantian sesi role; permintaan laporan terakhir kembali 200 dan tidak ada error menetap.

**Batas lanjutan:** Halaman PDF tengah, hasil dari printer fisik, dan seluruh kombinasi perangkat tidak diperiksa visual. UAT ini memakai data contoh pada database terpisah dan tidak menyatakan aplikasi siap untuk data sekolah atau deployment.

## Tindak lanjut: cetak ringkas dan pergantian role

Cetak *Laba rugi* kini menyembunyikan akun yang saldonya tepat Rp0 hanya pada media cetak; tampilan layar dan total dari API tetap lengkap. Akun dengan nilai tidak diketahui tetap terlihat. Pada preview lokal `:4173` dengan data demo utama, PDF Januari–Desember 2026 menjadi satu halaman A4; seluruh halaman diperiksa visual, termasuk total pendapatan Rp377.750.000, beban Rp275.500.000, dan laba Rp102.250.000. PDF sementara disimpan di `/tmp`, tanpa mengubah data demo.

Delapan respons 401 berhasil direproduksi saat Kepala Sekolah logout dari dashboard: watcher role memuat ulang endpoint setelah token dibersihkan. Watcher kini tidak memuat data setelah logout. Interceptor API juga menolak retry request dari sesi lama dengan token sesi baru, sambil tetap mendukung beberapa request kedaluwarsa dalam sesi yang sama. Pengulangan logout Kepala Sekolah tidak menambah respons 401 baru.

Sampel layar utama Admin TU (Data siswa), Keuangan dan Kepala Sekolah (Beranda), serta Guru PIC (Kegiatan) diperiksa pada viewport 1366 × 900 dan 400 × 900. Tidak terlihat elemen utama terpotong pada viewport yang diperiksa. Tes frontend setelah perubahan: 32 berkas / 131 tes lulus; build lulus dengan peringatan ukuran chunk utama yang sudah ada. Pemeriksaan ulang ini read-only pada database demo utama; semua perubahan tetap lokal.
